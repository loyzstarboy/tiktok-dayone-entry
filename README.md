Entry for the make.fun **"Day one, day seven"** TikTok bounty: a short TikTok video
showing a small game built by an AI agent, day one vs day seven — the rough first
version next to the polished one a week later.

`main.ts` copies `VIDEO.json` (which points at the published TikTok video) to the
output directory the make.fun gate reads. The video itself is the entry.

## Run it

```sh
node main.ts
```
